FYNN BILL REMINDER - hosting folder

1. Upload everything in this folder to a static host (Netlify, Cloudflare Pages, GitHub Pages).
2. Keep the file names exactly as they are. index.html is the app.
3. The site must be served over HTTPS so "Add to Home Screen" and offline mode work.
4. For the App Store / Google Play, use icon-1024.png as the store icon.
5. Cross-device sync only works inside Claude. On your own host, bills save on each device.
